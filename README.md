# sheik.portfolio

Personal portfolio for Daud — Builder, Trader & AI Agent Strategist.

Built with React, Vite, TypeScript, Tailwind CSS, and Framer Motion.

---

## Deploy & Get a Free URL

### Option A — Netlify (recommended)

1. Go to [netlify.com](https://netlify.com) and sign up / log in
2. Click **Add new site** → **Import an existing project**
3. Choose **GitHub** and select the `sheik.portfolio` repo
4. Build settings are auto-detected from `netlify.toml`:
   - Build command: `npm run build`
   - Publish directory: `dist`
5. Click **Deploy site**
6. Once deployed, go to **Site configuration** → **Site details** → **Change site name**
7. Set it to something like `daud-portfolio` → your URL becomes **daud-portfolio.netlify.app**

### Option B — Vercel

1. Go to [vercel.com](https://vercel.com) and sign up / log in
2. Click **Add New Project** → **Import Git Repository**
3. Select the `sheik.portfolio` repo from GitHub
4. Build settings are auto-detected from `vercel.json`:
   - Framework: Vite
   - Build command: `npm run build`
   - Output directory: `dist`
5. Under **Project Name**, type something like `daud-portfolio` → your URL becomes **daud-portfolio.vercel.app**
6. Click **Deploy**

---

## Add a Custom Domain Later

If you buy a domain (e.g. on Namecheap or Google Domains), you can connect it for free:
- **Netlify**: Site configuration → Domain management → Add custom domain
- **Vercel**: Project Settings → Domains → Add domain
